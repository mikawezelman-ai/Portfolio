Mijn basis

Wat ik meebreng

Technische kennis, een leergierige houding en aandacht voor de mensen met wie ik samenwerk.

01

Techniek

Deze onderwerpen komen terug in mijn opleiding en projecten.

  • HTML & CSS
  • JavaScript
  • PHP
  • Git & GitHub
  • API’s
  • Databases
  • Docker
02

Samenwerken

Ik stel vragen, bespreek ideeën en sta open voor feedback. Ik vind het belangrijk om technische keuzes begrijpelijk uit te leggen en verwachtingen af te stemmen.

03

Verder ontwikkelen

Ik wil meer ervaring opdoen met backend development, API-integraties, softwarearchitectuur en testen. Tijdens mijn stage wil ik leren van ervaren developers.

Mijn aanpak

Stap voor stap naar een oplossing

  1. Eerst begrijpen

    Wat is het probleem, wie gebruikt de oplossing en wat moet deze doen? Ik begin met analyseren en vragen stellen.

  2. Bouwen & overleggen

    Ik werk in overzichtelijke stappen, houd mijn code leesbaar en bespreek keuzes wanneer ik ergens tegenaan loop.

  3. Controleren & leren

    Ik controleer wat ik heb gemaakt, los fouten op en gebruik feedback om mijn werk en mijn aanpak te verbeteren.
